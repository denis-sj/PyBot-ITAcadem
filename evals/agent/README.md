# Эвалы агента

Запуск: `just eval-agent`. Нужен `POLZA_API_KEY`; используется `AGENT_MODEL`.
Это платные запросы к реальной модели. В CI эта команда не запускается.

`cases.json` содержит синтетические вопросы, роли, ожидаемые инструменты,
обязательные и запрещённые фразы. Runner использует тот же prompt, реестр,
проверки прав и проверку чисел, что runtime, без БД и Telegram.
`fixtures.py` заменяет операции чтения синтетическими результатами; ожидаемый набор
инструментов должен совпасть точно. Кейсы покрывают личные и административные
инструменты чтения, выбор месяца, пустой результат, поиск кандидатов для администратора,
заявку на роль и административное изменение с подтверждением, проверку роли и prompt injection. Runner печатает
имя кейса, статус и имена вызванных инструментов и завершается с кодом 1,
если хотя бы один кейс не прошёл. Семантическую точность отказов и удобство
формулировок нужно дополнительно оценивать руками на тестовом боте.
