# Встречи сообщества

Администраторы и менторы могут попросить ИИ-агента создать встречу. Укажите название, дату, время в формате `ЧЧ:ММ`,
место или ссылку и аудиторию. Агент покажет предварительный вариант с числом приглашённых и попросит подтвердить его
кнопкой. Неоднозначную компетенцию или технологию нужно уточнить.

Администратор может пригласить всех, участников с выбранной компетенцией или участников, указавших технологию в стеке.
Ментор может создать встречу только по своей компетенции или технологии, которую он отметил уровнем «знаю».
Время встречи указывается по Екатеринбургу и сохраняется в UTC.

Для встреч всем участникам бот публикует анонс с кнопками «Приду» и «Не смогу» в теме `EVENTS_CHAT_ID` / `EVENTS_TOPIC_ID`.
Название темы для предпросмотра задаётся через `EVENTS_TOPIC_NAME` и должно совпадать с названием темы в Telegram.
Если эта пара не настроена, используется тема агента `AGENT_GROUP_CHAT_ID` / `AGENT_TOPIC_ID`. Когда обе темы отсутствуют,
создать встречу для всех нельзя. Для аудитории по компетенции или технологии бот отправляет личные приглашения; пользователь
может отключить их в `/notifications`.

Нажать кнопку может участник аудитории или тот, кому доставили личное приглашение. Ответ можно менять до начала встречи.
Агент покажет ближайшие доступные встречи. Создатель и администратор могут запросить список тех, кто нажал «Приду»,
а также перенести или отменить встречу с подтверждением.

Тем, кто собирается прийти, бот отправляет напоминания примерно за сутки и за час. Если встреча создана менее чем за сутки,
напоминание за сутки не отправляется.
