# Мем недели из Lemmy

Статус: согласовано с владельцем 16.10.2026, к реализации. Пункты с пометкой «Допущение» можно поменять до разработки.

## Проверка источника (16.10.2026, с тестового сервера)

- `programming.dev` открывается с сервера без прокси. API `/api/v3/post/list` отвечает без ключа.
- Запрос `community_name=programmer_humor&sort=TopDay&limit=5` вернул 1 пост со score 267. Картинка лежит на другом сервере Lemmy (`sh.itjust.works/pictrs/...`).
- Вывод: мем раз в неделю выбирается из «лучшего за неделю», там кандидатов достаточно.

## Правила

### Когда и куда
- **Раз в неделю, в среду в 16:16** по Екатеринбургу. Один мем.
- Тема задаётся настройками `MEME_CHAT_ID` и `MEME_TOPIC_ID`. Если они не заданы, функция выключена.
- Не больше одного мема в неделю. Перезапуск бота не приводит к повторной публикации.

### Источник
- Список сообществ задаётся настройкой. По умолчанию `programmer_humor@programming.dev`. Другие IT-сообщества с юмором кодер проверяет через API и предлагает, сам не добавляет.
- Основной сервер — `programming.dev`. Запасной — `lemmy.world` (Допущение), запрос через него, если основной недоступен.
- Модель не используется, расходов на ИИ нет.

### Выбор мема
1. Посты всех сообществ из списка с сортировкой «лучшее за неделю», по убыванию рейтинга.
2. Первый подходящий пост. Подходит, если:
   - в посте есть хотя бы одна картинка: jpg, png, webp или gif;
   - пост не помечен 18+, не удалён и не снят модераторами;
   - этот мем ещё не публиковался. Сравниваются ID поста и ссылки на картинки;
   - рейтинг не ниже 20;
   - все картинки скачиваются и укладываются в лимиты Telegram.
3. Если подходящего нет — то же самое по «лучшему за месяц».
4. Если и там нет — на этой неделе мем не публикуется, в группу ничего не пишется, только запись в лог.

### Публикация — мем копируется целиком, без ссылки на источник
- Бот скачивает **все картинки поста**: картинку из ссылки поста и картинки внутри текста поста. Он отправляет их файлами в тему.
  - Одна картинка — фото. Одна GIF — анимация.
  - Несколько картинок — альбом, до 10 штук в порядке, как в посте. Если картинок больше 10, пост пропускается. Допущение.
- Подпись к фото или к первой картинке альбома:

  ```
  😂 Мем недели
  {заголовок поста}
  {текст поста, если есть}
  ```

  - Заголовок и текст на языке оригинала, без перевода.
  - Ссылки на источник нет.
  - Текст поста переводится из markdown в обычный текст: картинки из текста убираются, они уже в альбоме. Форматирование снимается, остаётся только текст.
  - Подпись отправляется без форматирования, это защита от разметки в чужом тексте.
  - Если подпись длиннее лимита Telegram (1024 символа), текст поста уходит отдельным сообщением сразу после картинок, в ту же тему.
- Посты-видео и посты, где ссылка ведёт на статью или сайт, пропускаются.

### Замена мема (для админов)
У альбома в Telegram не может быть кнопок, поэтому вместо кнопки — команда.
- `/meme_next` — только для роли Admin, работает в личке с ботом. Бот удаляет все сообщения текущего мема недели в теме и публикует следующий подходящий по тем же правилам.
- Заменённый мем помечается как показанный и больше не публикуется.
- Не больше 3 замен в неделю. Если кандидатов больше нет — ответ «Больше подходящих мемов нет».
- Повторная команда, пока идёт замена, не публикует второй мем.
- `/meme_now` — только для Admin. Публикует мем прямо сейчас по тем же правилам, чтобы проверить функцию. Не считается мемом недели и не отменяет публикацию в среду. Допущение.

## Безопасность

- **Предмодерации нет** — решение владельца 16.10.2026. Мем публикуется автоматически, исправить можно только через `/meme_next`.
- Запросы к Lemmy без ключей и без данных пользователей. Таймауты на все запросы.
- Картинки скачиваются только по `https`. Запрещены внутренние, частные и loopback-адреса, в том числе после переадресации (защита от SSRF). Проверяются тип файла по содержимому (сигнатура jpg/png/webp/gif) и лимит размера.
- Картинка не декодируется и не обрабатывается ботом: файл пересылается в Telegram как есть.
- Заголовок и текст поста отправляются без parse mode. ИИ в функции не используется.
- В логах нет содержимого постов, только ID поста, рейтинг и результат.

## Пограничные случаи

| Ситуация | Что происходит |
|---|---|
| Оба сервера недоступны | На этой неделе мема нет, ошибка в лог, в группу ничего не пишется. |
| Одна из картинок поста не скачалась или слишком большая | Пост пропускается целиком, берётся следующий, чтобы не публиковать мем частично. |
| Ссылка в посте ведёт не на картинку | Пост пропускается. |
| В тексте поста есть ссылки | Остаются как обычный текст. |
| Бота удалили из группы или лишили права писать в тему | Ошибка в лог, повторных попыток на этой неделе нет. |
| Админ удалил мем вручную и вызвал `/meme_next` | Публикуется следующий, отказа нет. |
| Альбом отправился частично (сбой Telegram посередине) | Отправленные части удаляются, пробуется следующий кандидат. |
